## ブラウザで開く手順

1. このリポジトリをクローンまたはダウンロードする
   ```
   git clone <このリポジトリのURL>
   ```
2. `company-site` フォルダに移動する
   ```
   cd company-site
   ```
3. `index.html` をブラウザで開く
   - macOSの場合: `open index.html`
   - Finder等でファイルをダブルクリックしても閲覧できます
